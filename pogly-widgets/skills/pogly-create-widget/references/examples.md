# Example widgets

Two calibration points: most widgets should look like the stopwatch, almost none should exceed
the poll.

## Stopwatch (the target level of minimalism)

Variables: fontColor (1) = "white", fontSize (1) = "25vw", font (1) = "Roboto", toggle (3) = false.
The toggle exists purely to restart the stopwatch: flipping it recompiles the iframe, which
resets the count. That is the idiomatic use of type 3.

Body:

```html
<div id="timer">00:00</div>
```

Style:

```css
body { background: transparent; margin: 0; }
#timer {
  font-size: {fontSize} !important;
  color: {fontColor} !important;
  font-family: {font} !important;
}
```

Script:

```js
var timer = document.getElementById("timer");
var seconds = 0, minutes = 0;
setInterval(function() {
  seconds++;
  if (seconds >= 60) { seconds = 0; minutes++; }
  if (minutes >= 60) { minutes = 0; }
  timer.textContent = (minutes < 10 ? "0" + minutes : minutes) + ":" + (seconds < 10 ? "0" + seconds : seconds);
}, 1000);
```

## Live variables in practice (fragment)

A goal label whose text and color can be retyped mid-stream without resetting the animation,
plus a button that fires a celebration:

Variables: label (1, live) = "Sub Goal", barColor (4, live) = "#9146ff",
celebrate (6, live) = "party" (buttons are always live).

```js
function onLiveVariableUpdate(name, value) {
  if (name === "label") document.getElementById("label").textContent = value;
  if (name === "barColor") document.getElementById("bar").style.background = value;
  if (name === "celebrate") document.getElementById("bar").classList.add("party");
}
```

Initial state still comes from `{label}` / `{barColor}` substitution in the body and style;
the handler only covers changes after load.

## Twitch chat poll (the complexity ceiling)

The full import JSON below is a real, working chat-vote widget: it opens an anonymous Twitch
IRC socket, counts keyword votes, animates in and out, and is driven by a type 3 toggle
(`enabled`) that starts a fresh poll on every flip because the flip recompiles the iframe.

Copy from it: the enter/exit animation catalog driven by a class + CSS variables, the
clamp()-based responsive type scale, the IRC connect/PING/PRIVMSG handling, deduping voters
with a Set, and cleanup via a destroy function.

Do NOT copy from it: the `typeof x !== "undefined"` fallback chains, the parse helpers, the
`if (!el) return` guard and the IIFE wrapper. Those predate the minimalism rule; trust
substitution and the DOM instead. Note it also uses `Date.now()` for the poll deadline, which
is fine (the deadline is relative to when this viewer's poll started) and `Math.random()` only
for the justinfan nick (the accepted use).
